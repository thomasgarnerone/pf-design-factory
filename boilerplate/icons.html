Icons

Curated Oxygen icon set — 128 of the most-used icons from the full @doctolib/icons package of 1,109. Each available in Regular and Solid weight.

Usage. Import directly from the icons package — e.g. import { CalendarRegularIcon } from '@doctolib/icons'. Icons are currentColor-aware (16×16 viewBox), so set colour via CSS. The full catalogue of 1,109 lives in packages/icons/src/generated-components/; this explorer covers the ~12% seen most in real Oxygen UI.
