Link & button variants

Style variants available on Link and Button beyond the primary set shown on their main pages.

From Oxygen core. Each component exposes a variant prop. Use subtle for body-embedded links; standalone for CTAs; danger for destructive actions.

Link variants

Standard: Book an appointment
Standalone (no underline until hover): Learn more →
Subtle: support documentation
Danger: Delete account
On-dark: Visit help center
Visited: Previously opened article

Button v2 variant recap

Button v2 has no success uiStyle — use brand for confirmation actions.
