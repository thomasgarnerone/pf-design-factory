PatientFileActionBar

Pre-composed <ActionBar> for the patient file workspace. Wires together the eight contextual cards every patient file needs — flow, documents, billing, treatment, bookings, care cooperation, patient actions — plus a feature-host injection slot for product-line extensions.

Composition, not a new component. This is just an <ActionBar> with a fixed set of children imported from @doctolib/pro-patient-file-v2-sdk, @doctolib/pro-financial-os-sdk, and the useFeatureHost injection point clinical:patient-file:action-bar. Use this in the patient file shell; use plain ActionBar for any other workspace.
