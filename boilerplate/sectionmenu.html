SectionMenu

Section navigation that auto-switches between tab strip (wide) and dropdown picker (narrow). Selected tab uses the inverted-surface token (dark fill, white text). Each item carries an active + inactive icon variant; arrow keys, Home/End, Enter and Space are wired for keyboard nav.

Container-aware. The component measures its own width and falls into dropdown mode when tabs would overflow — try the width controls below.
