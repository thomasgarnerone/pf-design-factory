CardCollection

Solid-card container with a heading row and a responsive 12-column masonry inside. Cards declare a size (xxsmall→xlarge→full); the collection maps it to grid spans across container-query breakpoints.

Container queries, not media queries. The reflow tracks the collection's own width — useful in split layouts where a column shrinks while the viewport stays wide. Default breakpoints at 1280 / 1024 / 768 / 640 px.
