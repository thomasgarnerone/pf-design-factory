QuickEdit

Inline-edit popover. A trigger element (typically an InlineButton) opens a small form floating over the page; the form holds one input (text / date / select / etc.) plus Cancel/Confirm. Used to edit a single field without leaving context.

Trigger is consumer-supplied. The component takes a render prop triggerButton({onClick}), so you decide what opens it. The popover is non-modal — clicks outside dismiss without saving.

Click any field to edit

When the value is empty, the confirm label defaults to "Add"; when populated, it defaults to "Edit".
