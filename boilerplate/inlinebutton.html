InlineButton

Editable text affordance — pairs an extra-small icon button with an inline label that inherits typography from its container. Used for inline-edit patterns and add-something prompts.

Inherits font & color by default. The label takes the surrounding text styles unless overridden via font / color. The icon button is always xsmall · transparent · neutral.
