dataDisplay / Pill

<Pill /> · recreation of packages/core/src/dataDisplay/Pill/Pill.scss & Pill.tsx. A tag / filter chip / selection chip. Props: color (9), size (3), selected, disabled, iconName, avatar, onDelete, rightIconName + onRightIconClick, notificationCount, loader. When onClick is set it renders as <button> and toggles dl-pill-interactive + dl-pill-clickable — gaining the inset ring + hover / active / focus states from the scss. Label font is Body/S/Regular on medium, else Body/XS/Regular.
